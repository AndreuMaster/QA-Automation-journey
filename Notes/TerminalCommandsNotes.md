# Notes and usefull comands to use git manually:
+ git checkout -b "XXXXX" -> Create a new branch
+ git push origin new-feature -> Push new changes to origin (origin is the repo in the cloud not in local)
+ git status -> You can check all the files, folders and modifications in local that were still not uploaded in a local or origin push
+ git commit -m "XXXXX" -> You create a commit
